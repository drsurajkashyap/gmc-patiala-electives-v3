# GMC Patiala MBBS Electives Counselling V3

Fresh landing page for the 2026 MBBS Electives Counselling system of Government Medical College, Patiala.

## Purpose

This repository contains the public information/entry page for V3 counselling. It explains:

- one global merit queue
- First Timeslot / Second Timeslot structure
- same-timeslot Block A + Block B selection
- live seat availability
- preference lookup near the student's turn
- counselling rules and final confirmation workflow
